# Emerald
에메랄드 승급과제


# 마우스 클릭으로 메인 메뉴에서 게임 시작 및 종료가 가능.
 
# WASD로 움직일 수 있으며 Shift를 누르면 달리기 Ctrl을 누르면 걷기가 가능합니다.

# 우클릭으로 조준을 하며 좌클릭으로 총을 발사할 수 있고, 'Z' 키를 눌러 근처에 적이 있으면 가장 가까운 적으로 락온 가능. 'X / C'를 눌러 다음 및 이전 적으로 락온 변경 가능.

# 1번이 총이고 3번이 칼이며 둘 다 공격가능

# 총의 데미지는 원할한 진행을 위해 높여둔 상태이며, 칼의 데미지는 90으로 설정해 한 번 공격 후 UI에 따라 처형을 할 수 있음.

# 맵이 복잡한 편이며 나오는 길을 따라 가다가 처음 3갈래 길에서 오른쪽으로 쭉 가면 미니 보스가 나오니 참고.

# 가던 중 중간에 붉은 구체가 특정 거리에 도달 시 데미지를 지속적으로 입는 장소.

# 미니보스를 잡고 난 뒤, 뒤쪽에 구체에 상호작용 시 체력과 탄창을 재보급 받을 수 있다.
